# Security Policy

## Reporting Vulnerabilities
If you discover a security vulnerability within Durable Agentic OS, please send an email to **manoj.elumalai@outlook.com**. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
